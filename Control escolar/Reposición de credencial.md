
# Reposición de credencial

Este trámite permite solicitar la reposición del plástico de la credencial de estudiante.

**Procedimiento:**

1. Envía un mensaje por **WhatsApp** o por el **chat de la plataforma**, solicitando apoyo de un asesor.
2. Al recibir respuesta, proporciona la información que se te solicite.
3. Comunícate con el área de **Caja** para que puedan generar el arancel correspondiente.

Una vez aceptado el trámite, realiza el pago correspondiente siguiendo estos pasos:

1. Ingresa al portal SIGE: [https://sige.iuv.edu.mx/panel/finanzas/plan-de-pagos](https://sige.iuv.edu.mx/panel/finanzas/plan-de-pagos)
2. Introduce tu usuario y contraseña.
3. Dirígete al módulo **Finanzas**.
4. Elige la opción **Plan de pago**.
5. Selecciona el concepto correspondiente a **Reposición de credencial**.
6. Sigue las indicaciones para realizar el pago.

**Precio del servicio:** $215.00.
