# ¿Qué documentación debo entregar para mi inscripción?

Todo depende del **nivel en que desees inscribirte**, por lo que podrás consultar los **requisitos específicos** directamente en la siguiente liga:

       **[Documentos para inscripción](https://view.genial.ly/60541093de068a0d8f517eb3/interactive-content-requisitos-de-inscripcion-a-maestrias%20)**

Si posterior a ello aún cuentas con alguna duda, podrás hacer el llamado de un asesor por medio de nuestros canales de comunicación vía WhatsApp o Chat de plataforma.
