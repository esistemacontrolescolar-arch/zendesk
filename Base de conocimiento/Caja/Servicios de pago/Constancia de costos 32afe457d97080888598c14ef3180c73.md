# Constancia de costos

Este documento proporciona información detallada sobre los costos relacionados con el programa que estás cursando. Incluye lo siguiente: Nombre del estudiante, matrícula, grado, programa que cursas, porcentaje de beca asignada, detalle de los costos de reinscripción y colegiaturas para cada ciclo escolar.

**Requisitos:**

- No tener **adeudos académicos** ni **administrativos**.

**Procedimiento:**

1. Ingresa al **Sistema de Gestión Escolar (SIGE)** en: [https://sige.iuv.edu.mx/](https://sige.iuv.edu.mx/)
2. Elige el módulo de **Control Escolar**.
3. Selecciona la opción **Constancias**.
4. Elige la **constancia** de tu interés.
5. Sigue los pasos indicados en la plataforma.

**Tiempo de entrega:** Podrás descargarla inmediatamente una vez completado el procedimiento y acreditado el pago.

**Precio del servicio:**

- *Normal* $190
- *Urgente* $230
