# ¿Qué pasa si se cumple el periodo de pago y no se efectúa?

Se aplicará un **recargo del 20%** sobre la **colegiatura con beca** si el pago se realiza después de los primeros 5 días naturales de cada mes.

Si deseas consultar **exactamente cuánto te corresponde pagar**, ingresa al **Sistema de Gestión Escolar (SIGE)**: [https://sige.iuv.edu.mx/auth/login](https://sige.iuv.edu.mx/auth/login), donde podrás ver todos los conceptos de pago, incluyendo los recargos aplicados.
