# ¿Cuáles son las formas de pago?

Para realizar tu pago, solo debes ingresar al **Sistema de Gestión Escolar (SIGE)** en el siguiente enlace:

[https://sige.iuv.edu.mx/auth/login](https://sige.iuv.edu.mx/auth/login)

Una vez dentro, la plataforma te mostrará las siguientes opciones para efectuar tu pago:

- **Tarjeta VISA**
- **SPEI (transferencia bancaria)**
- **OXXO**
- **Tiendas de conveniencia**

Selecciona la opción que prefieras y sigue las instrucciones correspondientes.
