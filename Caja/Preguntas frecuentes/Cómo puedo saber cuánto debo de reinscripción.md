# ¿Cómo puedo saber cuánto debo de reinscripción?

De manera anticipada, el área de **Control Escolar** te enviará por correo toda la información relacionada con tu **proceso de reinscripción**.

También puedes consultar el concepto a pagar directamente en el **Sistema de Gestión Escolar (SIGE)** ingresando a [https://sige.iuv.edu.mx/auth/login](https://sige.iuv.edu.mx/auth/login)

Una vez dentro:

1. Dirígete a la pestaña **Finanzas**.
2. Selecciona la opción **Plan de pago**.
3. Elige el concepto **Reinscripción** para conocer el monto correspondiente.
